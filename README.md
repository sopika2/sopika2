# Sopika

Software engineering and testing student in Hungary. I build web scrapers, data pipelines and small web products, and I test what I ship.

**Published work**

- [Google Ads Domain Checker](https://apify.com/saekoto/google-ads-domain-check) — Apify Store actor. Checks a list of domains against the Google Ads Transparency Center: advertising now or not, ad counts, last seen, formats, new and ended ads between runs. TypeScript, HTTP-only, fixture-tested, pay-per-event.
- [site-archive](https://github.com/sopika2/site-archive) — Python tool that documents a website before a redesign: Word content export, desktop and mobile screenshot PDFs, Excel sitemap with broken links.
- [Niijima network](https://niijimasisters.com) — a set of personal web apps (home, calendar, archive, finance tracker) sharing one design system. TypeScript.

**How I work**

- Parsers and pipelines get fixture tests before they get features
- Deliveries are validated for duplicates, missing fields and broken rows
- Runs fail loudly rather than return empty output
